
# 📊 ClassicModels Sales Dashboard — Power BI

A multi-page interactive sales analytics dashboard built in Power BI using the ClassicModels sample dataset. Designed to surface key business metrics, product performance, and customer distribution at a glance.

---

## 🚀 Overview

This dashboard helps stakeholders track sales performance across years, product lines, and geographies. It covers KPIs, product rankings, and regional customer distribution — all filterable in real time.

## 🗂️ Data Model

Built on the **ClassicModels** sample database with the following tables:

- `customer` — customer records and locations
- `employee` — sales rep data
- `office` — regional office details
- `order` & `order_details` — transactional sales data
- `payments` — payment records
- `product_line` & `products` — product catalogue

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** (January 2026)
- **DAX** — custom measures for profit margin, sales goals
- **Power Query** — data transformation and relationships
- **Bing Maps** — customer geography visual

---

## 📥 Getting Started

1. Clone or download this repository
2. Open `ClassicModels.pbix` in Power BI Desktop
3. Refresh data if connecting to a live database
4. Use the slicers to filter by year, city, employee, or product line
